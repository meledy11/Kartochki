V得… de степень

V + 得 + 补语 — как действие делается: степень и возможность
🏃
✓
跑得快
pǎo de kuài
бегает быстро
📌 他跑得快 Он быстро бегает.
🗣️
✓
说得好
shuō de hǎo
говорит хорошо
📌 你说得好 Ты хорошо говоришь.
😴
✓
睡得好
shuì de hǎo
спит хорошо
📌 昨晚睡得好吗？ Хорошо спал ночью?
🍜
✓
吃得起
chī de qǐ
по карману
📌 这家店我吃得起 Этот ресторан мне по карману.
💰
✓
买得起
mǎi de qǐ
могу купить
📌 这个我买得起 Это я могу купить.
📝
✓
做得完
zuò de wán
успею сделать
📌 今天做得完 Сегодня успею.
👂
✓
听得懂
tīng de dǒng
понимаю на слух
📌 中文我听得懂 Китайский я понимаю на слух.
📖
✓
看得懂
kàn de dǒng
понимаю прочитанное
📌 这个我看得懂 Это я понимаю при чтении.
🧠
✓
记得住
jì de zhù
могу запомнить
📌 名字我记得住 Имена я запомню.
🧍
✓
站得住
zhàn de zhù
могу устоять
📌 他站得住脚 Он твёрдо стоит на ногах.
🌅
✓
起得早
qǐ de zǎo
встаёт рано
📌 他每天起得早 Он каждый день встаёт рано.

✓
