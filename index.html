快 慢 马上 kuài / màn / mǎshàng такси 2

✓
麻烦快一点
máfan kuài yīdiǎn
Будьте добры, побыстрее
麻烦 = будьте добры (вежливо)
✓
能不能快点？
néng bù néng kuài diǎn
Можно побыстрее?
能不能 = можно ли (вежливый вопрос)
✓
我快迟到了
wǒ kuài chídào le
Я почти опаздываю
快 = скоро · 迟到 = опаздывать
✓
请开慢一点
qǐng kāi màn yīdiǎn
Поезжайте помедленнее
开慢 = вести медленно
✓
我马上下来
wǒ mǎshàng xiàlái
Я сейчас выйду (спущусь)
马上 = сейчас же · 下来 = спуститься
✓
我马上就到
wǒ mǎshàng jiù dào
Я сейчас приду
马上 = сейчас · 就 = уже · 到 = прибыть
✓
马上到
mǎshàng dào
Сейчас буду / Уже подъезжаю
马上 = вот-вот, сейчас (о себе)
✓
等我一下
děng wǒ yīxià
Подождите меня
等我 = подожди меня · 一下 = немного
✓
再等我两分钟
zài děng wǒ liǎng fēnzhōng
Подождите ещё две минуты
再 = ещё · 两分钟 = две минуты
✓
你到了吗？
nǐ dào le ma
Вы приехали?
到了 = прибыл · 吗 = вопрос
✓
我在门口等你
wǒ zài ménkǒu děng nǐ
Я жду вас у входа
在门口 = у входа · 等你 = жду тебя
✓
车在哪里？
chē zài nǎlǐ
Где машина?
车 = машина · 在哪里 = где
✓
在前面等
zài qiánmiàn děng
Ждите впереди
在前面 = впереди · 等 = ждать
✓
我穿黑色外套
wǒ chuān hēisè wàitào
Я в чёрной куртке
穿 = носить · 黑色外套 = чёрная куртка
✓
你的车牌号是多少？
nǐ de chēpái hào shì duōshǎo
Какой у вас номер машины?
车牌号 = номер машины
✓
麻烦你了
máfan nǐ le
Спасибо, извините за беспокойство
麻烦你了 = спасибо (с оттенком «извините»)
✓
到了我告诉你
dào le wǒ gàosù nǐ
Когда приедем — скажу
到了 = когда приедем · 告诉你 = скажу тебе
✓
我在这里
wǒ zài zhèlǐ
Я здесь
在这里 = здесь, на этом месте
